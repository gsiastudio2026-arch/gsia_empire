# Comment Contribuer à GSIA Empire

Bienvenue dans l'empire DG !

## Règles
1.  Toujours créer une branche pour tes modifications
2.  Pas de push direct sur `main`
3.  Tester avant de proposer

## Processus
1.  Fork le projet
2.  Clone ton fork
3.  Fais tes modifications
4.  Pull Request vers GSIA

Ensemble on construit BUTODRA.
